# Fixed-Wing eVTOL | Quadplane UAV

### Design, Aerodynamic Analysis, Fabrication & Flight Testing

**IIT Hyderabad | UAV Design and Development**

A fixed-wing electric Vertical Take-Off and Landing (eVTOL) UAV developed for surveillance and mapping applications. The project covers the complete aircraft development process, including preliminary sizing, CAD modelling, aerodynamic analysis, fabrication, subsystem integration, and flight testing.

## Aircraft Specifications

| Parameter | Specification |
|---|---|
| Configuration | Fixed-Wing Quadplane VTOL |
| Wingspan | 1.5 m |
| Maximum Take-Off Weight (MTOW) | 6 kg |
| Payload Capacity | 500 g |
| Target Cruise Speed | 20 m/s |
| Target Flight Endurance | 45 minutes |
| Wing Airfoil | NACA 4412 |
| Tail Airfoil | NACA 0015 |
| Airframe Material | Carbon Fibre and Foam |
| CAD Software | CATIA |
| CFD Software | ANSYS Fluent |
| Application | Surveillance and Mapping |

## Project Objectives

- Design a fixed-wing UAV capable of vertical take-off and landing.
- Achieve efficient forward flight while carrying a 500 g payload.
- Optimize aircraft sizing, configuration, and propulsion layout.
- Evaluate aerodynamic characteristics and aircraft stability.
- Fabricate, integrate, and flight-test a functional UAV prototype.

## 1. Aircraft Design and CAD Modelling

The aircraft was designed in CATIA using a quadplane configuration, combining four vertical lift motors with a fixed-wing propulsion system.

The design process included:

- Weight estimation and preliminary aircraft sizing.
- Wing and tail sizing with airfoil selection.
- Centre of Gravity (CG) estimation and static stability analysis.
- Fuselage, structural layout, and propulsion system integration.
- Complete aircraft CAD modelling.

## 2. Aerodynamic Analysis

ANSYS Fluent was used to evaluate the aerodynamic characteristics of the aircraft and support wing sizing and configuration development.

## 3. Fabrication and Assembly

The UAV airframe was fabricated using carbon fibre and foam materials.

Fabrication activities included airframe construction, structural assembly, propulsion system installation, and integration of onboard subsystems.

*Fabrication photographs and final prototype images will be added in Reference Folder.*

## 4. Flight Testing and Validation

The fabricated prototype underwent VTOL and fixed-wing flight testing.

Flight testing included:

- VTOL testing in QSTABILIZE and QLOITER modes.
- Autonomous QRTL flight testing.
- Fixed-wing transition testing.
- Comparison of flight performance with theoretical design calculations.
